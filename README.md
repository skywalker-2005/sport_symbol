# Символ Спорта

Адаптивная витрина наград на React и Vite.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки используйте `npm run build`, для локального просмотра
собранного сайта — `npm run preview`.

## Структура

- `src/data/products.js` — категории и карточки каталога.
- `src/components/` — секции сайта, карточка товара, иллюстрации и корзина.
- `src/hooks/useCart.js` — состояние корзины и сохранение в браузере.
- `src/App.jsx` — сборка страницы и связь пользовательских сценариев.
- `src/styles.css` — адаптивные стили.

Цены и иллюстрации демонстрационные. Формы и оформление заказа пока не
отправляют данные, онлайн-оплата не подключена.
